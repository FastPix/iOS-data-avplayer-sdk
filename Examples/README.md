# FastPix Video Data AVPlayer — Examples

Two standalone apps showing the **FastPix Video Data AVPlayer SDK** attached to
`AVPlayer`, one per UI paradigm:

- [`UIKit/`](UIKit) — `AVPlayerViewController` (iOS 14+)
- [`SwiftUI/`](SwiftUI) — `VideoPlayer` (iOS 16+)

Each folder is self-contained — open its `.xcodeproj`, press **▶ Run**, then
watch views on [dashboard.fastpix.com](https://dashboard.fastpix.com). Both
reference the SDK as a local Swift package (`../..`), so they build against this
checkout. See each project's README for details.
